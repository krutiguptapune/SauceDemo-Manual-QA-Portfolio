
# SauceDemo Manual QA Testing Portfolio

## Project Overview

This project demonstrates manual software testing of SauceDemo, a demo e-commerce web application.

The objective is to evaluate the application's functionality, identify defects, design test cases, and maintain professional QA documentation.

## Application Under Test

- Application: SauceDemo
- Website: https://www.saucedemo.com/
- Testing Type: Manual Testing
- Domain: E-commerce

## Project Objectives

- Prepare a comprehensive test strategy.
- Identify and document functional requirements.
- Design and execute manual test cases.
- Perform positive, negative, and boundary testing.
- Report defects with reproducible steps and evidence.
- Create a Requirements Traceability Matrix.
- Conduct exploratory testing sessions.
